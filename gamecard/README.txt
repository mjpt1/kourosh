راهنمای نصب / به‌روزرسانی روی سی‌پنل
=====================================
نیازمندی: PHP 8.0 یا بالاتر (در سی‌پنل: Select PHP Version) با افزونه‌های pdo_sqlite، mbstring و curl.

به‌روزرسانی سایت فعلی (mahsen81.ir/game):
1) فایل gamecard.zip را داخل پوشه public_html/game آپلود و Extract کنید و اجازه دهید فایل‌ها جایگزین شوند.
   پوشه data روی سرور (دیتابیس فعلی) دست نمی‌خورد و خودکار به نسخه جدید ارتقا پیدا می‌کند.
2) فایل .htaccess هم باید آپلود شود (در File Manager گزینه Show Hidden Files را روشن کنید تا ببینیدش).
3) وارد yoursite/game/admin شوید (رمز اولیه: admin1234) و از «تنظیمات و سئو»:
   - رمز مدیر را عوض کنید.
   - مرچنت کد زرین‌پال را وارد کنید. تا خالی باشد، مشتری‌ها نمی‌توانند پرداخت کنند (فقط خود مدیر برای تست).
   - لینک تلگرام، تلفن و کد اینماد را وارد کنید.

پنل‌ها:
- پنل مشتری: yoursite/game/account — هر خریدار هنگام اولین خرید خودکار حساب می‌گیرد و همه سفارش‌ها و کدهایش آنجاست.
- پنل مدیر: داشبورد فروش، سفارش‌ها (تحویل کد / پیام به مشتری)، محصولات، انبار کد، دسته‌ها، کاربران (بازیابی رمز، مسدودسازی)، تنظیمات و سئو.

سئو — کارهایی که باید خودتان انجام دهید:
- سایت را در Google Search Console ثبت کنید و آدرس sitemap.xml را آنجا Submit کنید.
- بهتر است فروشگاه روی دامنه اصلی (نه زیرپوشه /game) باشد؛ گوگل فایل robots.txt را فقط از ریشه دامنه می‌خواند.
- برای هر محصول و دسته توضیحات کامل و منحصربه‌فرد بنویسید (از پنل مدیر).
- اینماد بگیرید و HTTPS را فعال کنید (خط‌های مربوطه در .htaccess آماده‌اند).
